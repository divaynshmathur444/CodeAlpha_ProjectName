# Hangman Game

## Description

This is a simple text-based Hangman game developed in Python.

The player guesses one letter at a time until the complete word is revealed or the maximum number of incorrect attempts is reached.

## Features

- Random word selection
- Maximum 6 incorrect guesses
- Input validation
- Win/Lose conditions
- Console-based gameplay

## Concepts Used

- random module
- while loop
- if-else statements
- strings
- lists

## How to Run

```bash
python hangman.py
