# Stock Portfolio Tracker

## Description

This Python program calculates the total investment value of a stock portfolio using predefined stock prices.

Users enter stock symbols and quantities, and the program calculates the total investment.

## Features

- Predefined stock prices
- User input for stock names and quantities
- Total investment calculation
- Saves portfolio details to a text file

## Concepts Used

- Dictionary
- Input/Output
- Arithmetic Operations
- File Handling

## How to Run

```bash
python stock_tracker.py
